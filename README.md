Bank Management System (C++)
This project is a console-based Bank Management System developed in C++.
It allows users to perform basic banking operations through a simple and user-friendly menu interface.
The system is designed to demonstrate file handling, structured programming, and menu-driven application logic in C++.
Features
Create New Account
Open a new bank account by entering customer details.
Deposit Money
Add money to an existing account.
Withdraw Money
Withdraw funds with balance validation.
Check Account Details
View complete details of a specific account.
Modify Account Information
Update existing customer or account data.
View All Accounts
Display a list of all registered bank accounts.
Delete Account
Permanently remove an account from the system.
